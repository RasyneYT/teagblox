# Release Notes - ChatPlus Version CC1.0

## New Features

- **Private Chat Tab & Buttons:** Added a new "Private" tab to the chat UI featuring `+ Private` and `+ Group` buttons.

---

## Known Issues & Temporary Limitations

- **Data Persistence (DataStore):** Cross-game conversation persistence is not yet implemented in this release.
- **Room Creation Currently Unavailable:** A known bug currently prevents the active creation of new private conversations or groups when clicking the buttons. A fix will be deployed in an upcoming update.
